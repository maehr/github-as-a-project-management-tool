## Risks for the workshop run

| ID   | Risk                                                                              | Effect                                      | Response                                                                                                                           |
| ---- | --------------------------------------------------------------------------------- | ------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| R-01 | GitHub changes its interface before the session.                                  | Steps or screenshots do not match.          | Check every exercise on the day before. Each exercise links the official documentation.                                            |
| R-02 | A learner has no GitHub account, or two-factor authentication delays the sign-in. | The learner loses time in X1.               | Ask learners to create an account before the session. A learner without an account works in a pair.                                |
| R-03 | The template's workflows run in each new repository and fail.                     | Learners see red marks and receive e-mails. | X1 explains that the failure is expected. Learners can disable Actions in their repository.                                        |
| R-04 | GitHub has an outage.                                                             | Exercises cannot run.                       | Check [githubstatus.com](https://www.githubstatus.com/). Use the screenshots and the example repository to walk through the steps. |
| R-05 | A learner puts real thesis data into a public exercise repository.                | Unintended disclosure.                      | Use only the synthetic CSV. X1 includes a visibility check.                                                                        |
| R-06 | A feature behaves differently on a private repository on GitHub Free.             | Private-path learners get stuck.            | The exercises note each difference that the UI verification log confirms.                                                          |
| R-07 | The KSL rules are read as thesis rules.                                           | Wrong deadlines.                            | The [requirements register](../documentation/requirements.qmd) separates course facts from thesis rules.                           |
| R-08 | A two-week delay makes a learner move the submission date.                        | A silent change of an official deadline.    | X6 practises the opposite: move the planned work, keep the official date, record the decision.                                     |
